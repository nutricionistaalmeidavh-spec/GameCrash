# Brasil Crash — mapas e carros

Este diretório contém conteúdo 3D para integrar no GameCrash existente, sem criar uma segunda aplicação. A branch `feat/brasil-mapas-carros` mantém o trabalho isolado da `main` e do GitHub Pages. Os GLBs são assets procedurais originais low-poly, gratuitos e sem logotipos de montadoras. Não representam mapas geográficos exatos.

A integração deve utilizar o renderer/física já presentes no projeto quando forem implementados. As malhas de cenário são Y-up, metros, com início das rotas indicado no catálogo. O carro aponta para -Z.
